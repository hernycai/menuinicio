# Sincronización con GitHub

Este proyecto se publica en `https://github.com/hernycai/menuinicio`, rama `main`.

Cuando una solicitud cambie archivos del proyecto, al terminar agrupa los cambios de esa solicitud en un commit con mensaje descriptivo y haz push a `origin main`. Si el usuario pide expresamente no publicar, deja los cambios locales. No incluyas archivos ajenos a la solicitud ni secretos. Cada vez que se actualice la app, recompila el DMG, reemplaza `dist/Rojo-Inicio-1.0.0.dmg` y súbelo junto al código para que esté disponible para descarga. `build/` permanece local.
